# Стилист

Личное приложение для телефона: сканирует лицо онлайн, сравнивает с образом из референсов и подсказывает, что убрать, подрезать, оставить и где отращивать. Устройство и решения: `docs/ARCHITECTURE.md`, правила бровей: `docs/BROWS.md`.

Состояние: каркас. Работает ведение сканирования (подсказки про свет, резкость и тряску, съёмка по команде, серия кадров при движении волосков). Распознавание волосков ещё не написано.

## Запуск на компьютере

```
pip install -r server/requirements.txt
python -m server
```

Сервер напечатает адрес с токеном: `http://127.0.0.1:8000/?token=...`. Токен хранится в `data/token.txt` (или берётся из `STYLIST_TOKEN`). Снимки сеансов лежат в `data/scans/<сеанс>/`.

Тесты: `python -m unittest discover -q`.

## Телефон

Камера в Safari работает только по HTTPS, поэтому телефону нужен защищённый адрес вашего сервера. Два способа, оба нужно проверить при настройке:

- **Быстрый тест:** Cloudflare Quick Tunnel (`cloudflared tunnel --url http://127.0.0.1:8000`) выдаёт временный адрес вида `https://....trycloudflare.com`. Просто, но трафик (в том числе снимки) идёт через Cloudflare.
- **Для постоянной работы:** Tailscale на ноутбуке и на телефоне, `tailscale serve` даёт HTTPS внутри вашей частной сети без публичного адреса.

Откройте на телефоне адрес с `?token=...`. Первым делом зайдите на `/diag.html` и пришлите результат: он покажет, что реально умеет камера iPhone 11 в Safari.

Токен защищает сервер, но не заменяет решения про приватность: пока сервер на вашем ноутбуке, снимки остаются у вас.
