# Запуск у владельца (Windows, PyCharm)

Зачем: сервер должен работать на вашем ноутбуке, а телефон открывает его через интернет-адрес с HTTPS (без HTTPS камера в Safari не включится). Инструкция не проверена на Windows, поправим по первому запуску.

## Один раз

1. Поставьте Python 3.12 с python.org. На первом экране установщика поставьте галочку **Add python.exe to PATH**. (3.10 тоже работает, но его поддержка заканчивается в октябре 2026.)
2. В PyCharm: **Git → Clone** (на стартовом экране кнопка **Clone Repository**), адрес `https://github.com/St1o/stylist`. Проект откроется в новом окне.
3. PyCharm предложит создать окружение `.venv` на Python 3.12. Согласитесь.
4. Внизу откройте **Terminal** и выполните: `pip install -r server/requirements.txt`.
5. Для адреса с HTTPS поставьте туннель: `winget install Cloudflare.cloudflared`, потом закройте и снова откройте Terminal.

## Каждый раз

1. В Terminal: `python -m server`. Окно покажет адрес вида `http://127.0.0.1:8000/?token=...`. Не закрывайте.
2. Откройте второй Terminal (кнопка **+** вверху Terminal) и выполните: `cloudflared tunnel --url http://127.0.0.1:8000`. Через несколько секунд он напечатает адрес `https://что-то.trycloudflare.com`. Это временный адрес вашего ноутбука, трафик идёт через Cloudflare.
3. На телефоне откройте этот адрес и добавьте в конец `/diag.html`. Токен для этой страницы не нужен.
4. Нажмите «Запустить», разрешите камеру, дождитесь «Готово», нажмите «Скопировать» и вставьте результат в чат.

Для самого сканирования откройте адрес из шага 2, добавьте `/?token=` и токен (он лежит в файле `data/token.txt` и печатается при запуске сервера).

Остановить: красный квадрат в окне Terminal или Ctrl+C.
